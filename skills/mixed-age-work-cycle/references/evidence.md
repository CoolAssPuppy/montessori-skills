# Evidence: mixed-age-work-cycle

## Original Montessori

- *To Educate the Human Potential*, ch. II: different ages, different uses of the same material.
- AMI [Montessori 12-18](https://montessori-ami.org/resource-library/quotes/montessori-12-18), *From Childhood to Adolescence* p. 73: activity changeovers and quiet.

## Modern professional guidance

- AMS [core components](https://amshq.org/the-ams-difference/core-components-of-montessori/): mixed-age classrooms; uninterrupted work periods with current durations.
- [Essential Elements](https://amshq.org/wp-content/uploads/2025/01/EssentialElementspublicsector.pdf) p. 2 Curriculum/Environment: organize specialties around work periods. Late-1990s document; 90-minute range must not silently replace AMS current text.
