# Select work that shows change

Build an index of real samples. Caption what each one can show.

## When to use

The school keeps portfolios, or a conference needs work samples.

Narrative report: `progress-report-drafting`. Raw notes: `factual-observation-notes`.

## Inputs

- Work with dates and provenance
- Rubric or learning goals the school uses
- Child comments only if already spoken, written, or signed
- Photo permissions
- Audience: family, next teacher, accreditation visit, public display

## Procedure

1. Keep the school's selection rules if they exist. A6 names portfolios and performance tools.
2. Prefer process: drafts, revisions, different response modes (photo of a construction, AAC printout, video still the school already authorized).
3. Record independence vs help on each card.
4. Quote the child only from supplied wording. Empty child-voice field if none.
5. Balance: include struggle and incomplete work when it shows learning. A polished product or presence in a photo does not prove mastery.
6. Check permissions before any display beyond the intended audience. Public walls need a separate approval.
7. Optional FN photo reads (`photo_child_list`) are roster-adjacent. Minimize. Synthetic ids in examples.

NAEYC: culturally aware assessment; do not exclude assisted or AAC work.

## Output

Index rows: sample id, date, provenance, context, learning link (school goal ID), access notes, child voice (or none), audience, permission status.

## Adaptations

Accept video, object photos, and dictated text as samples.
