# Map the school's supplied curriculum

Organize what the school already approved. Do not write a new program.

## When to use

A guide or coordinator has albums, a scope-and-sequence, or standards and needs them in one traceable map.

Single lesson: `montessori-lesson-preparation`. Reports: `progress-report-drafting`.

## Inputs

- Curriculum files with IDs or lesson names
- Program (0-3, 3-6, 6-12, adolescent, mixed)
- School's status words (presented, practiced, mastered, etc.)
- Rubric if any
- What is explicitly out of scope

## Procedure

1. Import only supplied rows. Preserve IDs. If a lesson has no ID, use the school's name and page.
2. Group by the school's areas, not by a layout you prefer.
3. Mark **prerequisite** only when the supplied text says so. Other links are **optional connections**.
4. Define status words from the school's rubric. If the rubric is silent, propose definitions as **draft, needs owner**. Do not mark a child as having demonstrated work you have not been shown.
5. Age lens:
   - 0-6: movement, care, concrete materials (*Method*; *Handbook*)
   - 6-12: reasons, group work, cultural connections, hand plus imagination (*To Educate the Human Potential* I-II). Do not use the book's exclusionary or irreversible-late-learning claims as gates.
   - 12-18: academic, practical, social, artistic, reflective work the program actually lists (AMI 12-18 excerpts, pp. 60-75). Do not reduce this to a 3-6 shelf list. Land/economy examples are historical proposals.
6. Planes language (AMI quotation page) is a broad framework, not a test.
7. List gaps as "not in supplied files," not as "school is incomplete." *Method* ch. XX: sequence varies.

A6 Assessment mentions authentic tools. Mapping is not grading children.

## Output

- Table: ID, name, area, program lens, prerequisites, optional connections, status definition, evidence type the school uses
- Gap list
- Owner questions
- Source locators

## Adaptations

Include non-shelf work (going out, meetings, land work, internships) when the supplied program names them.

## Safeguards

No generated official standards. No age-guaranteed completion. Qualify M4/M5 theology, historical science, and exclusionary lines.
